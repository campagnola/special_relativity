How to Use the Relativity Simulator

📊 Worldline Plots (Top Panels)

Show spacetime diagrams where:

  • Horizontal axis: Position in space
  • Vertical axis: Time
  • Straight lines: Constant velocity motion
  • Curved lines: Acceleration
  • Dots: Proper time tick marks (black = forward, gray = backward)
  • Dashed line: Line of simultaneity in reference frame
  • Colored dots: Current positions of all clocks

🎬 1D Animation (Bottom Panels)

Real-time visualization showing:

  • Clocks: Colored circles representing objects
  • Length contraction: Moving clocks appear compressed
  • Proper time: Numbers next to clocks show their experienced time
  • Force arrows: Orange triangles indicate acceleration

⚙️ Controls

  • Duration: Total simulation time
  • Animation Speed: Playback rate (0.0001x to 10x)
  • Reference Frame: Choose viewing perspective
  • Time Slider: Scrub through animation manually

🕐 Creating Objects

Clocks: Individual objects with acceleration programs

Grids: Arrays of synchronized clocks

🚀 Acceleration Programming

Define motion with time-acceleration pairs:

  • τ (proper time): When to change acceleration
  • a (acceleration): New acceleration value

Example: [(0, 0.5), (3, 0), (8, -0.5)] = accelerate → coast → decelerate

🔬 Physics Concepts

  • Twin Paradox: Traveling twin ages slower
  • Simultaneity: "Now" depends on reference frame
  • Time Dilation: Moving clocks run slower
  • Length Contraction: Moving objects appear shorter
